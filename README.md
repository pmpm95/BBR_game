# 🍫 빼빼로데이 챌린지

팀원들이 웹에서 미니게임 3종을 즐기고, 결과가 메인 화면 랭킹 대시보드에 **실시간으로** 반영되는 사내 이벤트용 웹앱입니다.
종합 TOP 3에게 상품을 줍니다.

| 게임 | 방법 | 기록 | 점수 (0~1000) |
|---|---|---|---|
| 🃏 카드 짝맞추기 | 빼빼로데이 그림(빼빼로·하트·선물·장미·11.11 달력 등 18종) 36장을 4초 보여준 뒤 뒤집고, 같은 그림 찾기. 판은 매번 랜덤 | 완료 시간 | 20초 이내 1000점, 1초당 −8점 |
| ⏱️ 11초 11 맞추기 | 시간이 흐르다 3초 뒤 가려짐 → 감으로 정지 | 멈춘 시간 | 1000 − 오차(ms) |
| 🥢 11.11km 빼빼로 | 멀리서 목표선 확인 → 확대 → 스페이스바를 누르는 동안 가속하며 길어짐(빌딩·가로수 거리 횡스크롤) → 떼면 정지 | 완성 길이 | 1000 − 오차(m) |

- [플레이] → **게임 설명 팝업** → [시작하기] → **3·2·1** 카운트다운 후 게임 시작
- **게임당 3번까지** 도전할 수 있고, 게임마다 **최고 기록**만 반영됩니다.
- **종합 점수**는 세 게임 최고 점수의 합(최대 3000점)입니다. 동점이면 그 점수에 먼저 도달한 사람이 위입니다.
- 참가자는 각자 받은 **4자리 개인 코드**로 본인 인증을 합니다.
- 점수 공식과 게임 설정은 모두 `public/js/shared/rules.js` 한 파일에 모여 있습니다. 브라우저와 서버가 같은 파일을 씁니다.

> 💡 **사내 서버 없이 Microsoft Copilot Managed Runtime(managedapps.cloud.microsoft)에 올리려면**
> [`managed-app/README.md`](managed-app/README.md) 를 보세요. 회사 계정 자동 로그인 + 내장 저장소를 쓰는 버전입니다.

## 구조

```
server/            Node.js 서버 (외부 패키지 없음)
  index.js         HTTP API, 정적 파일 제공, 실시간 갱신(SSE)
  store.js         JSON 파일 저장소 (data/db.json)
  leaderboard.js   랭킹 계산
public/            프론트엔드 (빌드 과정 없는 순수 HTML/CSS/JS)
  index.html       메인 화면 = 게임 목록 + 랭킹 대시보드
  admin.html       관리자 페이지 (/admin)
  js/shared/rules.js  게임 규칙, 점수, 결과 검증
  js/games/        cards.js, stopwatch.js, pepero.js
scripts/gen-codes.js  참가자 코드 생성
data/              players.json(이름·코드), db.json(기록) ← git에 올라가지 않음
```

## 사내 서버 배포

필요한 것은 **Node.js 18 이상**뿐입니다. `npm install`도 필요 없습니다.

```bash
git clone <repo> pepero && cd pepero

# 1) 참가자 11명의 코드를 생성합니다. 출력된 표를 각자에게 개별로 전달하세요.
npm run gen-codes -- 김민수 이서연 박지훈 ...
#    또는 이름을 한 줄에 한 명씩 적은 파일로: npm run gen-codes -- --file names.txt

# 2) 서버를 실행합니다.
ADMIN_PASSWORD='관리자비번' EVENT_END='2026-11-11T18:00:00+09:00' PORT=3000 npm start
```

이제 팀원들은 `http://<사내서버IP>:3000` 으로 접속하면 됩니다.

| 환경 변수 | 설명 | 기본값 |
|---|---|---|
| `PORT` | 포트 | `3000` |
| `HOST` | 바인딩 주소 | `0.0.0.0` |
| `ADMIN_PASSWORD` | 관리자 페이지 비밀번호. 설정하지 않으면 관리자 기능이 꺼집니다 | (없음) |
| `EVENT_END` | 이 시각이 지나면 자동으로 마감되고 랭킹이 동결됩니다 (ISO 형식) | (없음) |
| `DATA_DIR` | 데이터 저장 위치 | `./data` |

서버를 계속 띄워두려면 다음처럼 실행하세요.

```bash
# pm2 사용
ADMIN_PASSWORD=... EVENT_END=... pm2 start server/index.js --name pepero
```

```ini
# 또는 systemd: /etc/systemd/system/pepero.service
[Service]
WorkingDirectory=/opt/pepero
Environment=PORT=3000 ADMIN_PASSWORD=... EVENT_END=2026-11-11T18:00:00+09:00
ExecStart=/usr/bin/node server/index.js
Restart=always
```

nginx 뒤에 둘 경우 실시간 갱신(`/api/stream`, SSE)이 끊기지 않도록 `proxy_buffering off;` 를 설정하세요.
설정하지 않아도 20초마다 자동으로 새로고침되긴 합니다.

### 모바일 접속

- 앱은 반응형이라 휴대폰에서도 플레이할 수 있습니다. 터치용 버튼도 있습니다.
- 접속 가능 여부는 네트워크에 달려 있습니다.
  - 휴대폰이 **사내 Wi-Fi에 연결되어 있고** 그 Wi-Fi에서 서버 IP에 접근할 수 있으면 접속됩니다.
  - **LTE/5G**나 게스트 Wi-Fi로는 사내 서버에 닿지 않으므로 접속되지 않습니다(VPN을 쓰면 가능).
- 미리 사내 Wi-Fi에 연결한 휴대폰으로 `http://<서버IP>:3000` 이 열리는지 확인해보세요.

## 운영 (관리자 페이지 `/admin`)

- 전체 도전 기록 확인 (완료 / 중단 / 거절)
- **기록 삭제**: 삭제하면 해당 참가자의 기회 1회가 복구됩니다. 오류로 날린 판을 구제할 때 사용하세요.
- **지금 마감**: 즉시 랭킹을 동결합니다. `EVENT_END`로 자동 마감도 가능합니다.
- CSV 내보내기, 전체 초기화 (사전 테스트가 끝난 뒤 사용)

> ⚠️ **게임을 시작하는 순간 기회 1회가 차감됩니다.** 중간에 창을 닫거나 새로고침하면 그 판은 기록 없이 소진됩니다.
> 결과를 전송하다 네트워크 오류가 나면 브라우저에 보관해 두었다가 다음 접속 때 자동으로 다시 전송합니다.

## 공정성 장치

- 점수는 **서버에서만** 계산합니다. 클라이언트는 원본 데이터(뒤집기 기록, 정지 시간, 누른 시간)만 보냅니다.
- 카드 배치는 서버가 섞어서 내려주고, 서버가 클릭 기록을 **리플레이해서** 완료 시간을 다시 계산합니다.
- 모든 게임 기록은 "서버에서 측정한 시작부터 전송까지의 시간"보다 길 수 없습니다.
- 도전 1회당 결과는 한 번만 저장되고, 코드 입력은 IP당 10분에 10회까지만 실패할 수 있습니다.
